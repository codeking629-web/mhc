# Mặc Hương Các — Studio Dịch Truyện Chữ Trung - Việt AI

Ứng dụng biên dịch, biên tập và đọc truyện chữ Trung - Việt chuyên sâu bằng AI (Next.js 15 + Gemini Interactions API).

## Chạy Local

**Yêu cầu:** Node.js 18+

1. Cài đặt thư viện:
   ```bash
   npm install
   ```
2. Khởi chạy ứng dụng:
   ```bash
   npm run dev
   ```
3. Mở trình duyệt tại `http://localhost:3000`, vào mục **[Preset & Model → Bể 50 Key & Kiểm Tra API]** để tự dán Gemini API Key cá nhân của bạn vào rồi bấm **Lưu** trước khi dịch (dự án không tích hợp sẵn bất kỳ API Key nào trong `.env`).
